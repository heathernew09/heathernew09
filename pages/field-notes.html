Meal Planning

Mel

111 recipes deep and growing. Mel runs the household meal-plan session, pulling from a curated recipe library and building weekly plans on demand. What's really cool is that Mel pushes the grocery list directly to a shared reminder list between my wife and I. If an ingredient is already in our pantry, it doesn't get added. Repeat ingredients across multiple recipes get combined automatically, no duplicates, no guesswork at the store.

I keep learning more about what this can do. I hope to add some automation and potentially delivery integration. It may also become a locally hosted touchscreen in the kitchen so I can pull up the recipe digitally, right now we keep paper copies in alphabetical order that we pull when it's time to cook. So far it's been a wonderful tool, helping us save money while enjoying meals we actually love.

In Progress
Origin

How It Started

The NuTone name comes from the vintage intercom brand, the kind of whole-home audio system that was built into houses in the 60s and 70s. The idea: bring that concept back, but with modern hardware and a touchscreen interface built from scratch. No subscription. No cloud dependency. Just music, on demand, in the room you're in.

Tech Stack

The Build

Raspberry Pi running a custom touchscreen interface. Plex Media Server handles the local library. The Billie agent connects the dots, taking requests, queuing tracks, managing playback across rooms.

  • Raspberry Pi
  • Plex Media Server
  • Billie Agent
  • Custom Touchscreen UI
  • Local Music Library
