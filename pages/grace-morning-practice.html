01. The Capability

What is Grace?

Grace is a locally-hosted AI agent running an autonomous daily art practice. Every morning at 6:45am, she evaluates a set of thematic rules, constructs a highly specific visual prompt, and pushes it through a local stable diffusion pipeline. A custom dashboard tracks her daily progress without human intervention.

02. The Architecture

ComfyUI Setup

The system operates entirely on local hardware. A chron job triggers a Python script that asks an LLM to generate the prompt. This prompt is then sent via API directly into a local ComfyUI instance running SDXL.

> INIT: grace_agent.py > POST: http://127.0.0.1:8188/prompt > STATUS: Queued for rendering.
03. Thematic Selection

Curating Themes

Grace doesn't hallucinate randomly; she selects from structured JSON dictionaries. Her prompts explore specific intersections: Tactile Materials (brass, wood, anodized aluminum) colliding with Abstract Concepts (nostalgia, tension, friction). This structured randomness forces highly unique prompt construction.

04. Open Source Potential

Releasing the Code?

The pipeline is fully modularized into discrete blocks: the theme generator, the LLM prompt writer, and the ComfyUI API bridge. It is heavily segmented, making it a prime candidate for a public GitHub repo. Anyone with a local GPU could retrace these steps, build their own dashboard, and run their own agent.
