## 🏗 Technical Architecture

- **Vite-Powered Pipeline:** Modern build toolchain for optimized asset delivery and decoding.
- **JSON-Driven Gallery:** Dynamic project rendering from `projects.json` for rapid content iteration.
- **Modular Component Engine:** High-speed build-time HTML injection for reusable nav, footers, and interactive heroes.
- **Automated DevOps:** Custom Bash-based deployment pipeline syncing local builds to SiteGround with automated backups and cache invalidation.
- **Interactive UI:** Custom 3D tilt effects, physics-based game loops (Flappy M, Parasite Hunter), and SVG logic trees.

## 📂 Directory Structure

- `public_html/`: Application root and sub-pages.
- `public/`: Production assets (Images, Videos, Data, Compiled JS).
- `src/partials/`: Modular HTML components for build-time injection.
- `dist/`: Optimized production build (generated).
- `ProjectAssets/`: (Local Only) Raw design files, PSDs, and project archives.

## 🛠 Local Development & Deployment

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run dev server (Live Reload):**
   ```bash
   npm run dev
   ```
3. **Deploy to production (Verify & Upload):**
   ```bash
   ./deploy.sh
   ```
